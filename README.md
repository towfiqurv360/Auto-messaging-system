**NeuralReply** is an enterprise-grade, background daemon that intelligently intercepts mobile notifications, processes conversational context using the Google Gemini LLM, and dispatches human-like responses seamlessly without waking the device UI. 

Coupled with a sleek, glassmorphism-inspired Next.js dashboard, it offers real-time monitoring of live execution logs directly from a Supabase database.

---

## ✨ Enterprise Features

* **🧠 Context-Aware AI:** Powered by `gemini-1.5-flash` to generate contextual, friendly, and precise replies based on the sender's prompt.
* **⚡ Zero-UI Dispatch:** Operates completely in the background via MacroDroid, hooking directly into Android notification intents.
* **🛡️ Smart Firewall & Refusals:** 
  * **Selective Ignore:** Automatically bypasses specific senders (e.g., Boss, Family Groups).
  * **Group Mention Filter:** Ignores group chat mentions (`@`) to prevent spamming.
  * **Boundary Control:** Politely declines answering sensitive, unknown, or inappropriate questions.
* **🎭 Emoji Mirroring:** Detects pure emoji messages and dynamically mirrors the exact expression back without generating unnecessary text.
* **📊 Real-Time Telemetry:** A high-performance dashboard fetching dispatched logs instantaneously from Supabase.
* **🎨 Premium UI/UX:** Built with Tailwind CSS featuring a Bento Grid architecture, dynamic Dark/Light modes, skeleton loaders, and interactive transitions.

🚀 Installation & Local Setup
Prerequisites
Node.js (v18 or higher)

A Google Gemini API Key

A Supabase Account & Project

An Android Device with MacroDroid installed


1. Web Deployment (Next.js)
Clone the repository and install the required dependencies:

Bash
git clone [https://github.com/your-username/neural-reply.git](https://github.com/your-username/neural-reply.git)
cd neural-reply
npm install
2. Environment Variables
Create a .env.local file in the root directory and populate it with your secure keys:

Code snippet
GEMINI_API_KEY=your_google_gemini_api_key
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
3. Database Schema (Supabase)
Execute the following SQL query in your Supabase SQL Editor to create the required table:

SQL
CREATE TABLE message_logs (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  sender text not null,
  message text not null,
  reply text not null
);
4. Run the Development Server
Bash
npm run dev
Navigate to http://localhost:3000 to view the dashboard. For the Android integration to work, deploy this project to Vercel to get a live URL.

📱 Mobile Configuration (MacroDroid)
To bridge your Android device with the NeuralReply engine, configure MacroDroid as follows:

Trigger: Notification Received -> Select Apps (e.g., Messenger) -> Text Content: Any.

Action 1 (API Request):

Add HTTP Request.

Method: POST | URL: https://your-vercel-domain.vercel.app/api/chat

✅ Check "Block next actions until complete".

✅ Check "Save HTTP response in string variable" (Name it api_response).

Content Type: application/json

Content Body:

{
  "sender": "[not_title]",
  "message": "[notification_ticker]"
}
Action 2 (Silent Dispatch):

Add Notification Interaction -> Reply.

Reply Text: [lv=api_response].
